
# E-Commerce Analytics Data Pipeline

A Python-based e-commerce data pipeline 

## Objectives

- Design a normalized PostgreSQL database.
- Implement transactional database operations with Python and psycopg2.
- Use PostgreSQL JSONB for flexible product metadata.
- Cache popular products with Redis.
- Store user session and shopping-cart data in MongoDB.
- Develop analytical SQL queries using CTEs and window functions.
- Measure and improve query performance using EXPLAIN ANALYZE and indexes.

## Technology Stack

- Python 3.11+
- PostgreSQL
- Redis
- MongoDB
- Docker Compose
- pytest
- Ruff and Black
